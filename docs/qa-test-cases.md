# NPB チャット Q&A テストケース集

実際に API に投げた質問と回答の記録。バグ修正前後の挙動も含む。

**凡例:**
- **（確認済み）** — ローカル dev サーバーで実際に確認した動作
- **（ローカル確認 — 本番要確認）** — ローカルでは batting_lines/pitching_lines/events が空のため0件だが、クエリパーサーの出力は確認済み。本番 DB にデータがある場合は正しい結果が返ることを期待
- **（修正後・確認済み）** — バグ修正後にローカルで正しい動作を確認済み
- **（本番要確認）** — デプロイ後に本番 API で確認が必要

**ローカル DB の制限:**
- `player_batting_stats` (BIS公式集計): 2026年のみ 947行あり → search_batting は動作する
- `current_team_roster`: 2026年のみ 1098行あり → 選手解決は動作する
- `batting_lines` / `pitching_lines` / `events` / `roster_entries`: 空 → aggregate_batting/pitching/events, search_batting(ランキング), search_roster は0件
