# プライバシーポリシー

制定日: 2026年5月17日

本プライバシーポリシーは、NPB Archive Chat（以下「本サービス」）における利用者情報の取り扱いを定めるものです。

## 1. 取得する情報

本サービスは、以下の情報を取得することがあります。

| 区分 | 内容 | 取得方法 |
|------|------|----------|
| ゲスト識別子 | 本サービスが発行するランダムなユーザー ID | 署名付き cookie |
| Google アカウント情報 | Google アカウントの一意 ID、メールアドレス、メール確認状態、表示名 | Google ログイン |
| アカウント情報 | 表示名、メールアドレス、プラン、課金状態 | 利用者入力、Stripe webhook |
| 課金情報 | Stripe 顧客 ID、Stripe サブスクリプション ID、Stripe Price ID、Checkout Session ID | Stripe Checkout / webhook |
| 利用状況 | 月ごとのチャット利用回数、利用プラン | 本サービス利用時 |
| 技術情報 | cookie、アクセス日時、リクエスト URL、エラー情報、Cloudflare による通信ログ | サービス提供基盤 |

本サービスは、クレジットカード番号を直接保存しません。
支払い情報は Stripe が処理し、本サービスは Stripe から発行される顧客 ID やサブスクリプション ID など、課金状態の管理に必要な識別子だけを保存します。

## 2. 利用目的

取得した情報は、以下の目的で利用します。

- 本サービスのアカウント識別
- Google ログイン済みアカウントと課金状態の紐づけ
- Free / Pro プランの判定
- チャット利用回数の計測
- Stripe Checkout、Billing Portal、webhook による課金管理
- 問い合わせ対応
- 不具合調査、セキュリティ対策、 abuse 防止
- サービス改善

## 3. Cookie の利用

本サービスは、以下の cookie を利用します。

| cookie | 用途 |
|--------|------|
| `npb_chat_user` | ゲスト利用者の識別 |
| `npb_auth_user` | Google ログイン済み利用者の識別 |
| `npb_google_oauth_state` | Google OAuth の CSRF 対策 |

cookie を削除すると、ゲスト利用の識別子は失われます。
Google ログイン済みの場合は、再ログインにより同じ Google アカウントに紐づくアカウントを復元できます。

## 4. 外部サービス

本サービスは、以下の外部サービスを利用します。

### Google

Google ログインにより、Google アカウントの一意 ID、メールアドレス、メール確認状態、表示名を取得します。
本サービスが要求するスコープは `openid email profile` です。
Google Drive、Gmail、Calendar などのデータにはアクセスしません。

### Stripe

Pro プランの決済、サブスクリプション管理、請求管理に Stripe を利用します。
本サービスは、Stripe から通知される課金状態をもとに、利用者のプランを更新します。

### Cloudflare

本サービスは Cloudflare Workers、D1、R2 などの Cloudflare サービス上で動作します。
通信ログやセキュリティ関連ログが Cloudflare により処理される場合があります。

## 5. 第三者提供

本サービスは、以下の場合を除き、利用者情報を第三者に提供しません。

- 利用者本人の同意がある場合
- 決済、認証、インフラ提供など、本サービス提供に必要な外部サービスに処理を委託する場合
- 法令に基づく場合
- 不正利用、セキュリティ事故、権利侵害への対応に必要な場合

## 6. 保存期間

本サービスは、利用目的に必要な範囲で情報を保存します。

- ゲスト account は、cookie が削除されると利用者側からは復元できません
- Google ログイン済み account は、退会または削除依頼まで保存される場合があります
- 課金履歴に関係する情報は、会計、請求、不正防止、問い合わせ対応に必要な期間保存される場合があります
- ログは、運用、障害調査、セキュリティ確保に必要な期間保存される場合があります

## 7. 利用者による確認・削除依頼

利用者は、自身のアカウント情報の確認、修正、削除を求めることができます。
Google アカウントとの紐づけや課金状態の確認には、本人確認のため、対象の Google アカウントまたは Stripe の課金情報を確認する場合があります。

問い合わせ先は本ドキュメント末尾を参照してください。

## 8. セキュリティ

本サービスは、署名付き cookie、Google OAuth、Stripe webhook signature 検証など、必要なセキュリティ対策を講じます。
ただし、インターネット上の通信やシステム運用に完全な安全性を保証するものではありません。

## 9. 未成年の利用

未成年の利用者は、親権者など法定代理人の同意を得たうえで本サービスを利用してください。

## 10. 変更

本プライバシーポリシーは、必要に応じて変更されることがあります。
重要な変更がある場合は、本サービス上または適切な方法で通知します。
