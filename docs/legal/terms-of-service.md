# 利用規約

制定日: 2026年5月17日

本利用規約（以下「本規約」）は、NPB Archive Chat（以下「本サービス」）の利用条件を定めるものです。
利用者は、本サービスを利用することで、本規約に同意したものとみなされます。

## 1. 本サービスの内容

本サービスは、保存済みの NPB 試合履歴データ、正規化データベース、補助的な AI 生成処理を用いて、NPB の試合履歴に関する検索・チャット回答を提供するサービスです。

本サービスにおいて、AI は一次情報ではありません。
回答の根拠は、原則として本サービスが保持するデータベースおよび source URL です。

## 2. アカウント

本サービスは、以下の利用状態を提供します。

| 状態 | 内容 |
|------|------|
| ゲスト | cookie により一時的に識別される無料利用 |
| Google ログイン済み無料 | Google アカウントに紐づく無料利用 |
| Pro | Google アカウントに紐づく有料サブスクリプション |

ゲスト状態は cookie に依存します。
cookie を削除した場合、ゲスト状態の利用履歴や識別子は復元できません。
有料プランの利用には Google ログインが必要です。

## 3. Free プラン

Free プランでは、月ごとのチャット利用回数に上限があります。
現行の上限は、UTC 暦月あたり 9 回です。
基本的な DB 検索 API には、別途明示しない限り、このチャット回数制限は適用されません。

## 4. Pro プラン

Pro プランは月額 980円のサブスクリプションです。
決済、請求、支払い方法の管理は Stripe により処理されます。

Pro プランでは、チャット利用回数の月次上限を設けません。
ただし、障害、不正利用、過度な負荷、技術的制約がある場合には、一時的に制限を行うことがあります。

## 5. 課金、更新、解約

Pro プランは Stripe subscription として管理されます。
利用者は、Stripe Checkout または Billing Portal を通じて、支払い方法の登録、請求情報の確認、解約などを行います。

サブスクリプションの状態は Stripe webhook により本サービスへ反映されます。
Stripe 側の処理遅延や webhook 到達遅延により、アプリ上の表示に反映されるまで時間がかかる場合があります。

## 6. 返金

返金の可否は、個別の状況に応じて判断します。
法令上必要な場合を除き、利用者都合による返金には応じられない場合があります。

返金に関する問い合わせは、本規約末尾の問い合わせ先へ連絡してください。

## 7. 禁止事項

利用者は、以下の行為をしてはなりません。

- 法令または公序良俗に反する行為
- 本サービスの運営を妨害する行為
- 不正アクセス、脆弱性探索、過度な負荷をかける行為
- API や UI を通常想定される範囲を超えて機械的・大量に利用する行為
- 第三者になりすます行為
- 本サービスの回答を、出典確認なしに公式記録または保証された事実として扱う行為
- 本サービス、第三者、NPB 関係者その他の権利を侵害する行為

## 8. データと出典

本サービスは、保存済み raw HTML、structured JSON、normalized DB、source URL をもとに回答します。
ただし、データ欠損、解析誤り、更新遅延、表示上の誤りが含まれる可能性があります。

重要な判断に利用する場合は、必ず公式サイトなど一次情報を確認してください。

## 9. AI 生成回答

本サービスでは、structured query generation や回答文の整形に AI を利用する場合があります。
AI 生成部分には誤りが含まれる可能性があります。
本サービスは、AI の出力内容の完全性、正確性、最新性を保証しません。

## 10. サービスの変更・停止

本サービスは、事前の通知なく、機能の追加、変更、停止、終了を行うことがあります。
メンテナンス、障害、外部サービスの停止、法令対応などにより、一時的に利用できない場合があります。

## 11. 免責

本サービスは、可能な限り正確な情報提供に努めますが、提供情報の完全性、正確性、有用性、特定目的への適合性を保証しません。

本サービスの利用により利用者に生じた損害について、運営者は、故意または重過失がある場合を除き、責任を負いません。

## 12. 外部サービス

本サービスは、Google、Stripe、Cloudflare などの外部サービスを利用します。
これらの外部サービスの利用には、それぞれの規約やポリシーが適用されます。
外部サービスの障害、仕様変更、アカウント制限などにより、本サービスの一部機能が利用できなくなる場合があります。

## 13. 規約の変更

本規約は、必要に応じて変更されることがあります。
重要な変更がある場合は、本サービス上または適切な方法で通知します。
変更後に本サービスを利用した場合、利用者は変更後の規約に同意したものとみなされます。

## 14. 準拠法・管轄

本規約は日本法に準拠します。
本サービスに関して紛争が生じた場合、運営者所在地を管轄する日本の裁判所を第一審の専属的合意管轄裁判所とします。
